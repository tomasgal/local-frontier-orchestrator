Operation rules:
- SET_TEXT: current scalar text value.
- SET_INTEGER: current integer value. target MUST contain only an optional leading minus sign and decimal digits, e.g. 64. Never wrap the number in braces, brackets, units, or prose; use "32", not "{32}" or "32 GB".
- SET_REAL: current real-number value. target MUST use invariant decimal notation with '.', e.g. 83.5.
- SET_BOOLEAN: current boolean value. target MUST be exactly true or false.
- ADD_RELATION: subject is explicitly related to another entity; target is that entity mention.
- A correction is simply another SET_* operation for the same subject + predicate with the new current value.
- Do not emit duplicate operations inside one turn.
- subject and target are surface mentions, not canonical identifiers. Preserve a short useful form from the evidence; the wrapper resolves entity identity.
- Do not invent aliases or rewrite a mention merely to make it look canonical.
- predicate must be concise lowercase snake_case.
- subject_type and target_entity_type are lightweight descriptive hints such as computer, gpu, server, person, project; they are not entity identity.
- target_entity_type MUST be empty for every SET_* operation.
- target_entity_type may be used only for ADD_RELATION.
- Emit [] when this pass establishes no suitable L2 fact.
