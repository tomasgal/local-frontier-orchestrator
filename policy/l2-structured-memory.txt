Emit memory_ops only for durable factual state or explicit relations established by this evidence and accepted by the current Qwen pass. Do not infer hidden facts, preferences, motives, or uncertain claims. Ignore older context unless this turn re-establishes the fact. Return [] if none.

- SET_BOOLEAN: exactly true or false.
- ADD_RELATION: explicit relation to another entity.
- Correction: SET_* with the new value.
