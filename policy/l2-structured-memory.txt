{{L2_EVIDENCE_SCOPE}}

memory_ops: durable facts in evidence. No guesses, preferences, old-only facts, metadata or duplicates; [] if none.
SET_* target is LITERAL: target_entity_type MUST be "" even for OS/product names. ADD_RELATION target is ENTITY: set target_entity_type (e.g. gpu).
SET_INTEGER: /^-?\d+$/ (no units/braces); SET_REAL: dot-decimal; SET_BOOLEAN: "true"/"false"; SET_TEXT: full name + version.
Use observed names and stable snake_case predicates: os, database, cpu, ram_gb, nightly_backups_enabled, has_gpu, vendor.
Correction: SET_* with SAME subject + predicate; new target.

Examples: op | subject | predicate | target | target_entity_type (add subject_type)

"LYRA CPU is i5-6500" => SET_TEXT | LYRA | cpu | i5-6500 | ""
"LYRA has 48 GB RAM" => SET_INTEGER | LYRA | ram_gb | 48 | ""
"LYRA has RX6600 GPU" => ADD_RELATION | LYRA | has_gpu | RX6600 | gpu
"RX6600 is AMD" => SET_TEXT | RX6600 | vendor | AMD | ""
