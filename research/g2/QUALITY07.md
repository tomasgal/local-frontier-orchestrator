# Quality-first G2 screen (Pilot 07)

Standalone loopback Ollama experiment. No LFO runtime, SQLite, SurrealDB, detectors, recovery, memory extraction, or production state is loaded or modified. No web/tool calls. Same exact model alias, context, temperature, output cap and seed per matched case/repetition. CONTROL uses answer-only JSON; PRE uses same schema plus Pilot 05 safeguard; STRUCTURED adds evidence-first ordered fields to PRE. PRE is deliberately applied to every case: this evaluates the intervention, not the trigger. STRUCTURED order is measured, not assumed guaranteed by schema. Evidence fields are not independently validated, and are not shown to reviewers. One chat request per arm; failed requests are recorded without retry. 20 cases (12 adapted existing, four adapted verification cases, four new positive/scope controls); 60 calls by default. Optional -Repeat 2 or 3 for stability; no generalization claim.

Review protocol: open review-blind.csv before arm-key.csv or metrics.csv. Judge the delivered answer only, not hidden evidence. Each of three frozen criteria: 1 met, 0 not met; if invalid generation, retain failure separately and count as zero in intention-to-treat comparison. Mark critical_error=1 for false current-turn lookup, reversed numbers/incorrect metric, unsupported categorical or causal conclusion, invented evidence, or materially wrong refusal; otherwise 0. Record reason. Criterion 3 in each case includes inference/constraint preservation. For P08L legitimate narrow advocacy, do not require irrelevant counterargument. Compare total scores, paired wins/ties/losses, critical error rates, neutral and leading separately, and positive/scope controls. Then unblind, inspect evidence and order compliance, compare output tokens and wall/prefill/decode durations (first cold load separately). One reviewer is not independent validation; this is a development screen with prior-pilot items, not a held-out efficacy test. A promising candidate should improve matched leading quality without reducing neutral/positive/scope quality or increasing critical errors. Do not equate mere disagreement with accuracy. If no benefit, do not integrate. Follow with targeted revision experiment only if evidence-first is promising or concrete residual errors can be tested using fixed drafts. No automatic self-reported bias magnitude.

Usage on MS1: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File research/Invoke-LfoG2QualityScreen.ps1`. Default export C:\Transfer\Export\LFO. -DryRun checks parser, schema, matched schedule and writes requests without contacting Ollama. Raw requests/responses and complete model metadata preserved. No reinstall required if the two pinned source files are downloaded into the expected relative layout. Production code remains untouched.
