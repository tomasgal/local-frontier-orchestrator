# Pilot 09 — author-compiled epistemic requests

Goal: test whether explicit separation of task, hypothesis, evidence and constraints improves first-pass answers or targeted revisions. No general regex parser, no LFO runtime changes, no L1–L3 changes. Compilation is manually authored before generation. All nonempty evidence fields are exact substrings of original requests; hypotheses/task/constraints are manually restated. Compiler may remove a requested unsupported conclusion or false verification assertion but must preserve the legitimate task, hypothetical assumptions, preferences and scope. No answer key or rubric is included in requests. This is an upper-bound intervention test, not evidence that automated compilation works.

FIRST: 16 cases (8 known risk-leading cases, four previously tested controls including two neutral cases, and four new author-written cases: missing base rate, hypothetical assumption, explicit preference, fictional quotation). CONTROL raw; PRE raw + Pilot 07 safeguard; COMPILED typed request + same safeguard plus instructions for typed representation. 48 calls. REVISION: 14 exact frozen drafts from Pilot 08 selection; nine critical defects, one omission, four controls. TARGETED raw request + draft + fixed feedback; COMPILED_REVISION typed request + same draft and feedback. 28 calls, 14 baseline review rows (no calls). 76 calls, 90 rows total. FIRST COMPILED also tests independent re-solving on overlapping cases without exposing original drafts or feedback, but do not pool across groups or claim controlled isolation of anchoring. Same model digest, seed within pair, cap, temperature and context, think=false; fresh requests; no retries. Original source archive and per-answer hashes validated. Errors retained; on revision failures original is delivered.

Review blind: original prompt and three criteria, no arm identifiers. Score 0/1 per criterion, critical errors separately. For new quote/hypothetical cases distinguish claims of assistant action from fictional or conditional content. Then unblind: compare matched first-pass score, critical errors, controls, latency/tokens; revision repair rate and preservation of original valid content. First-pass screening target: COMPILED improves critical error count vs both comparators on 8 known risk prompts and introduces no critical errors in controls; revision target at least 8/9 critical errors repaired, all 4 controls preserved. Report results for new cases separately; small authored sample, no independent validation. No readiness points merely for technical PASS. If promising, test automatic semantic compilation separately and measure extra calls; no production integration until end-to-end benefit.

Run with explicit -BankPath and -InputZip, defaults resolved after param binding. -SelfTest validates frozen bank and request construction without calling model. Export includes manifest, raw requests/responses, blind review, metrics, arm key and frozen drafts.
