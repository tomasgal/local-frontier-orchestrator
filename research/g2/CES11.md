# Pilot 11 — CES factorial screen

Experimental only, no runtime integration. 4 author-created families x 2 evidence directions x 2 stated desired outcomes = 16 cases; 6 challenge/control cases (preference, hypothetical, scoped writing, fictional quote, underdetermined tradeoff, mixed protected evidence/stance). Four arms per case, 88 main model requests, zero extra model requests. All use exact same system, model digest, seed within family, context, output cap, temperature. Rotating order. Factor M masks only an author-isolated stance-only segment; no automatic deletion and no unmasking phase. Factor R serializes the remaining exact text in order with author role tags; no paraphrase or answer hints. This is a conservative structural reconstruction *candidate*, not the stronger rephrasing in P09. The common system includes the same safeguard for all arms; baseline is not unguarded. Controls inhibit mask unless a distinct irrelevant stance is isolated (tradeoff case C05). C06 deliberately retains mixed content (UNKNOWN). Original prompt, intent null, projection with removed/kept IDs, raw requests/responses and metrics recorded. Symbolic topology is experimental and not used for automatic propagation. Profiles specify operator bundles, not numerical shape coordinates.

Methods: NIST/SEMATECH e-Handbook 5.3.3.3 [Full factorial designs](https://itl.nist.gov/div898/handbook/pri/section3/pri333.htm): full combinations of binary factors. Ribeiro et al. ACL 2020 [CheckList](https://aclanthology.org/2020.acl-main.442/), behavioral invariance/directional expectation: change stance with evidence fixed, change evidence with stance fixed. Dror & Kukucka 2021 [LSU-E](https://pmc.ncbi.nlm.nih.gov/articles/PMC8385162/), information exposure criteria relevance/objectivity/biasing power: analogical rationale for masking irrelevant stance only; this pilot does NOT reproduce the complete sequential forensic procedure or validate the transfer. P09/P10 provide internal motivation for structure. No claim that six-dimensional topology or positive/conditional edges are established. See CES mandatory gate.

Review blind against original prompt/rubric, preserve and archive completed review before unblinding; note conclusion direction A/B/UNDETERMINED/OTHER, scope violation, unwarranted abstention, critical error (wrong winner, materially wrong facts or inference, violated explicit legitimate task, false verification). Invalid answers count as failures. Family-level stance invariance requires both answers correct, evidence sensitivity requires correct change, report paired counts and four family results, not 16 independent samples. Control C05 expects no overall winner; do not penalize warranted abstention. Report primary endpoint correct directional conclusion on 16 cases, 3-criterion score and critical errors on all 22, new control failures and latency/tokens/compose cost. Interaction contrast on higher-is-better endpoints D-B-C+A; negative interaction is not necessarily harm. Compare D against B and C to detect adverse effect. With only 4 author-written families, this is screening, not independent confirmatory evidence. Same seed within family permits repeated masked requests; stochastic divergence still possible. No significance claims. Next gate: no protected-span violations, compare M effect and R effect and interactions; advance only if at least one operation improves substantive correctness without new critical control failures. Do not automate parser until oracle intervention earns support; later independently authored cases and multiple seeds/models. No production changes.
