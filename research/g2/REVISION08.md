# G2 quality gate / Pilot 08

Development target: 92/100 on the previously defined engineering readiness rubric, not a population accuracy estimate. No new runtime feature in this experiment. Keep OBSERVE as default until validated. The previous quality screen found limited quality gains and repeated false verification claims. Test revision efficacy conditional on feedback before investing in automatic detection.

Frozen input: exact Pilot 07 archive SHA-256, 14 selected drafts (9 critical defects, 1 omission, 2 correct controls, 2 correct controls with deliberately questionable feedback). These are selected development cases, not a prevalence sample. Original source IDs, hashes, prompts, rubric and drafts are preserved. No new baseline generation: BASELINE is the already observed draft, 0 calls. Four matched revision arms, 56 calls, 70 blind review rows. One request per arm; same model digest, seed per draft, context, temperature and cap. GENERIC gets original prompt and draft; TARGETED adds a specific feedback signal; GROUNDED adds compact relevant source facts; PATCH gets identical grounded data and emits up to three exact old/new replacements, or KEEP/REWRITE_REQUIRED. Structural rejection preserves the original, no retry. REWRITE_REQUIRED is an escalation recommendation, not correction. Compare PATCH with GROUNDED to isolate edit representation. All requests say no external lookup occurred.

Review blind before unblinding. Use the same three binary criteria and critical-error rule from Pilot07; also compare against original draft for preservation of valid facts and task fulfillment. Count invalid responses and REWRITE_REQUIRED as unrepaired original when computing delivered quality; separately report structural failure and escalation frequency. Report number of original critical defects resolved (out of 9), omission repaired (out of 1), controls preserved (out of 4), new critical errors and paired changes; do not infer general efficacy from selected cases. Measure output tokens, wall time and preserved character fraction on PATCH vs GROUNDED, and note the first cold load. Grounded feedback is provided by the experimenter (oracle-like); noisy controls test inappropriate intervention, not detector accuracy. No automatic bias classification or hidden model call. No integration until a promising technique is found. Initial screening target: at least 8/9 critical defects resolved, all four controls retain valid content without new critical errors, and PATCH materially reduces median output tokens versus full grounded revision without worsening quality. These are engineering screening gates, not statistical guarantees. Later held-out cases, multiple seeds/models and independent human ratings are necessary before claiming 92/100 readiness. No model or memory changes.

Run with -InputZip pointing to the original archive (not the scored CSV), -BankPath optionally explicit. -SelfTest executes eight structural fixtures without model or files. Output raw requests and responses, exact frozen drafts, arm-key.csv, review-blind.csv, metrics.csv, manifest.json.
