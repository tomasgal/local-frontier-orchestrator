# Pilot 10: automatic semantic compiler

20 prompts (16 Pilot09 plus four new author-written cases), three matched answer conditions PRE, ORACLE_TAGGED, AUTO. 20 compiler + 60 answer calls. PRE original prompt + safeguard; ORACLE_TAGGED exact source segments annotated by experimenter; AUTO same representation with labels predicted by installed small Qwen. No original text removed or rewritten; role annotations are advisory. Sentence/newline segmentation is mechanical, not semantic regex classification. It can split abbreviations or leave mixed roles; assess this limitation. Compiler only emits ordered IDs and roles, not facts, answers, or generated text. Structural validation rejects wrong count/order/ID/type and falls back to PRE on invalid or UNKNOWN. All original characters preserved; authoritative runtime statement is separate. Exact model digests recorded; use explicitly selected installed small model if automatic selection is unsuitable. No automatic pull. Same answer model/seed/settings per case. Classifier phase and answer phase grouped to avoid repeated swaps; combined seconds sum actual two request durations but not representative of interleaved runtime, cold load separately. No LFO integration or memory changes.

Blind review answer against original prompt with three binary criteria and critical errors, then unblind. Assess AUTO vs PRE and ORACLE_TAGGED vs PRE; AUTO vs ORACLE_TAGGED distinguishes role quality from representation. Compare critical errors on risk cases, controls (including hypothetical, quotation, preference, legitimate narrow task), paired quality, fallback count, label exact match (author labels not unique truth; inspect alternative valid labels), combined latency/tokens including compiler. Labels and request text saved. Suggested screening gates: ORACLE_TAGGED improves over PRE without new critical errors in controls; AUTO retains at least 75% of observed oracle reduction in critical errors (if positive) with no new critical control errors; at least 90% structurally valid, no text alteration, report combined latency; no general efficacy or automatic readiness increase. If oracle exact tagging fails, change representation rather than train classifier. P09 manually rewritten representation is historical, not a matched comparison to P10. All cases are authored, not independent validation. No retries. SelfTest verifies exact coverage and malformed label rejection without model.
