# Documentation archive

This directory preserves historical development notes, experiment plans and
evaluation records that are no longer part of the primary `docs/` navigation
surface. The files remain useful for provenance and reconstruction, but their
status is superseded by the canonical frozen baselines or implementation
summaries listed below.

Do not treat archived PENDING/NEXT-step language as current project instructions.
